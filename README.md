# 八中校友回忆录

北京八中校友回忆网站，讲述校园故事与青春记忆。

## 项目说明

- 纯 HTML/CSS/JS，无框架
- GitHub Pages 部署
- 个人网站风格，注重叙事与情感表达

## 设计方向

- 编辑杂志风格（Editorial / Magazine）
- 温暖的怀旧色调
- 注重排版和阅读体验
- 适度的滚动动画增强沉浸感

## 技术栈

- HTML5
- CSS3（自定义属性、Grid、Flexbox）
- Vanilla JavaScript
- Google Fonts CDN

## 本地运行

直接打开 `index.html` 即可预览。

## 部署

GitHub Pages，从 main 分支部署。
